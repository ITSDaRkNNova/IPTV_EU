# 📺 Актуальні OTT Телеканали (Також будуть оновлення репозиторія)

**Збірка робочих українських телеканалів у форматі M3U8 для перегляду на будь-яких пристроях.**

Усі посилання перевірені на працездатність скриптом-чекером, а неробочі трансляції повністю відфільтровані.

---

## 🚀 Швидкий старт

Щоб запустити канали, просто скопіюйте посилання нижче та вставте його у свій IPTV-плеєр як мережевий потік або URL-плейлист:

```text
https://user.github.io/repository/playlists/playlist.m3u
```

> ⚠️ **Важливо:** Не забудьте замінити `USER` на нікнейм у GitHub, а `REPOSITORY` і `playlist.m3u` — на назву репозиторія і на назву плейлиста, щоб посилання запрацювало.
